# Garmin Dashboard

AI has made coding an unrewarding process. This dashboard is a small side project I am committing myself to without the use of any AI to remind myself that problem solving and writing code is why I fell into this type of work.

The dashboard is built on Astro, talking to Garmin Connect's personal API. As a V1, I intend to display:

- Last night's sleep and sleep history.
- Recent runs and gym sessions.
- Basic activity statistics and weekly totals.
- Daily resting heart rate and HRV.
- Seven-day and thirty-day trends.
- The most recent successful sync and any sync errors.
